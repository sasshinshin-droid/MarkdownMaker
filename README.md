# 📄 MarkdownMaker

**PowerPoint to Markdown Converter with Enhanced MarkItDown Integration**

*🤖 Generated with [Claude Code](https://claude.com/claude-code) via Phase 4 Workflow Engine*

## 🎯 Overview

MarkdownMaker is a comprehensive tool for converting PowerPoint presentations to Markdown format with intelligent handling of complex slides through image generation and AI interpretation using the MarkItDown library.

## ✨ Key Features

### 🔍 **Smart Slide Analysis**
- Analyzes PowerPoint (.pptx) files using python-pptx
- Counts objects (shapes, text boxes, images, charts, tables) per slide
- Identifies complex slides with 5+ objects requiring enhanced processing

### 🖼️ **Intelligent Image Generation**
- Converts complex slides (5+ objects) to high-quality PNG images
- Maintains aspect ratios and readable resolution (300 DPI)
- Uses PIL/Pillow for optimized image processing

### 🧠 **MarkItDown Integration**
- Integrates with MarkItDown library for AI-powered conversion
- Passes generated images to MarkItDown for LLM interpretation
- Supports Mermaid diagram generation from complex layouts
- Preserves original PowerPoint structure for simple slides

### 📋 **Advanced Output Management**
- Generates clean, structured Markdown with proper headings
- Includes image references with relative paths
- Maintains slide hierarchy and navigation
- Supports custom output directory structure

### 💻 **Command-Line Interface**
- argparse-based CLI with comprehensive options
- Configurable object threshold (default: 5)
- Batch processing support for multiple files
- Verbose logging and progress indicators

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/sasshinshin-droid/MarkdownMaker.git
cd MarkdownMaker

# Install dependencies
pip install -r requirements.txt
```

### Basic Usage

```bash
# Convert a single PowerPoint file
python markdown_maker.py presentation.pptx

# Convert with custom threshold
python markdown_maker.py presentation.pptx --threshold 3

# Batch processing
python markdown_maker.py *.pptx --batch --output-dir ./converted

# Verbose mode
python markdown_maker.py presentation.pptx --verbose
```

## 🏗️ Architecture

- **PowerPointAnalyzer**: Analyzes .pptx files and counts objects
- **SlideImageGenerator**: Converts complex slides to images
- **MarkItDownConverter**: Integrates with MarkItDown library
- **OutputManager**: Handles file organization and Markdown generation
- **MarkdownMakerApp**: Main application orchestrator

## ⚙️ Configuration

Create a `config.yaml` file to customize behavior:

```yaml
object_threshold: 5
image_dpi: 300
output_dir: "output"
generate_mermaid: true
preserve_structure: true
batch_mode: false
verbose: false
```

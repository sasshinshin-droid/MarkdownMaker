## README.md

```markdown
# MarkdownMaker

[![Python Version](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Code style: black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)
[![PyPI version](https://badge.fury.io/py/markdownmaker.svg)](https://badge.fury.io/py/markdownmaker)

An AI-powered document conversion tool that transforms PowerPoint presentations and other documents into clean, structured Markdown files. MarkdownMaker leverages advanced AI processing to extract content intelligently while preserving document structure and formatting.

## 🚀 Features

- **PowerPoint to Markdown**: Convert PPTX files to clean, structured Markdown
- **AI-Powered Processing**: Intelligent content extraction and formatting
- **Batch Processing**: Convert multiple files at once
- **Customizable Output**: Flexible formatting options and templates
- **Image Extraction**: Automatic extraction and linking of embedded images
- **Structure Preservation**: Maintains slide hierarchy and content organization
- **CLI Interface**: Easy-to-use command-line interface
- **Configuration**: Extensive customization through YAML configuration files
- **Multiple Formats**: Support for various input document formats

## 📦 Installation

### From PyPI (Recommended)

```bash
pip install markdownmaker
```

### From Source

```bash
git clone https://github.com/yourusername/markdownmaker.git
cd markdownmaker
pip install -e .
```

### Development Installation

```bash
git clone https://github.com/yourusername/markdownmaker.git
cd markdownmaker
pip install -e ".[dev]"
```

## 🛠 Quick Start

### Basic Usage

Convert a single PowerPoint file:

```bash
markdownmaker convert presentation.pptx
```

Convert with custom output directory:

```bash
markdownmaker convert presentation.pptx --output ./output/
```

Batch convert multiple files:

```bash
markdownmaker convert *.pptx --output ./markdown_files/
```

### CLI Commands

#### Convert Command

```bash
markdownmaker convert [OPTIONS] INPUT_FILES...

Options:
  -o, --output PATH          Output directory (default: current directory)
  -f, --format TEXT          Output format (default: markdown)
  -t, --template TEXT        Template to use for conversion
  -c, --config PATH          Configuration file path
  --extract-images          Extract and save images
  --image-dir PATH          Directory for extracted images
  --preserve-structure      Preserve original document structure
  --ai-enhance              Enable AI-powered content enhancement
  --batch-size INTEGER      Batch processing size (default: 10)
  --verbose                 Enable verbose logging
  --help                    Show this message and exit
```

#### Configuration Command

```bash
markdownmaker config [OPTIONS]

Options:
  --init                    Initialize default configuration
  --edit                    Open configuration file in editor
  --validate               Validate configuration file
  --show                   Display current configuration
```

#### Template Management

```bash
markdownmaker template [OPTIONS] COMMAND

Commands:
  list                     List available templates
  create NAME              Create new template
  edit NAME                Edit existing template
  delete NAME              Delete template
```
